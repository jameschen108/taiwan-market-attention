# 台股長尾關注度（v2）

投資人在市場關閉時累積的關注度，會不會反映在下一週的股價上？

Li, Liu, Ye, Zhao & Zhao 的 *"It Depends on When You Search"*（MIS Quarterly、
[SSRN 4370525](https://ssrn.com/abstract=4370525)）用 S&P 500（2004–2019）的
Google 搜尋量發現：週末的異常搜尋量預測次週報酬，週間的不預測。本專案把同一個研究
設計搬到台股長尾個股，改用 PTT 股板的發文數衡量關注度。
刻意偏離原論文之處逐項列於 [`PROJECT.md`](PROJECT.md) §0.2。

v2 是 `taiwan-attention-long-tail`（v1，未公開）用新語料重做：改用 ptt.cc 直爬，
換到帶留言帳號與時戳的資料，期間縮短為 2020–2024。全部階段已完成，327 項測試通過。

> **使用前必讀**
> - 所有結果均為 **diagnostic**：新聞量、分析師覆蓋、四因子等授權資料未取得，
>   因此不構成正式結論。換語料不解除這個標記。
> - 推論母體只能寫「本樣本涵蓋之 267 檔個股」，不能寫「台股」（見下方〈樣本〉）。
> - 引用任何結果都必須同時引用 [`LIMITATIONS.md`](LIMITATIONS.md)。

## 主要發現

詳見 [`FINDINGS.md`](FINDINGS.md)，括號內為章節。名詞說明見下方〈名詞速查〉。

1. **市場關閉時累積的關注度，預測下一週的開盤缺口（§4）。** 非交易時段的異常關注度
   正向預測次週第一個交易日的開盤缺口；交易時段累積的關注度則沒有可偵測的關係。
   這個對比在三個規格 × 兩種推論標準 × 有無排除漲跌停的十二種組合中全部 1% 顯著。
   效果穩定但不大：關注度高一個標準差，缺口高 5.2 個基點，約為缺口平均的三分之一、
   標準差的 3.8%。
   - 這是**預測關係，不是因果**：因果識別的事件研究在本設計下無法識別（§6.4）。
   - 這**不是可交易的訊號**：策略最早只能在開盤那一刻成交，正好錯過缺口；
     依同一訊號建構的投資組合扣除成本後六個版本全部顯著為負（§8.2）。
   - 原論文沒有把開盤缺口分離出來，所以這是本研究新增的證據，**不是複製**（§3）。

2. **原論文的週末效果在本樣本上是否顯著，取決於估計方式（§7）。** 照原論文的做法
   （個股固定效果、只按個股 cluster），週末係數在三個規格上都 1% 顯著；照本研究的
   主規格（個股＋週固定效果、個股＋週雙重 cluster），三個規格都不顯著。

3. **原論文「週間／週末」的切法在台股會混淆（§5）。** 週間窗口的關注度有 77% 發生在
   收盤之後，而週末只佔市場關閉期間關注度的 20.2%。用日曆切，兩個窗口都帶著
   同一個訊號，分不開；改用市場開關來切，對照才乾淨。

4. **機制分不開（§6）。** 專案事前設計了幾項檢定，用來區分「資訊處理」與「價格
   壓力」兩種解釋，結果沒有一項能判別：有的兩種解釋都預測，有的結果形狀兩者都沒
   預測，有的換一種關注度測度就不成立。

5. **新語料比舊封存少 14%，而且不是隨機的（[`LIMITATIONS.md`](LIMITATIONS.md) §2）。**
   2020–2024 的 ptt.cc 直爬語料（143,637 篇）完全包含在舊的 pttweb.cc 封存
   （167,142 篇）之內，少掉的 23,505 篇是官方已刪文，集中在 `請益`、`心得` 兩類。
   詳見 [`audit/P0_corpus_integrity.md`](audit/P0_corpus_integrity.md)。

## 樣本

| | |
|---|---|
| 個股 | 267 檔上市普通股（有效 260 檔），28 個 TWSE 產業別 |
| 選樣規則 | 每個產業依證券代號升冪取前 10 檔 |
| 期間 | 2020-01-12 ~ 2024-12-29，260 週；2019 只作回顧窗的暖機期 |
| 語料 | ptt.cc 股板直爬，143,637 篇文章、1,563 萬則留言（含 2019） |
| 面板 | 64,980 列（個股 × 週） |

台股代號大致依上市先後編配，所以這個選樣規則選出的是每個產業中上市年資最深的
10 檔：成立年份偏老、規模偏中小，金控與主要權值股（聯發科、廣達、中華電等）不在
樣本內。這就是推論母體只能寫「本樣本涵蓋之 267 檔個股」的原因。

## 名詞速查

| 名詞 | 意思 |
|---|---|
| 異常關注度 | 某檔股票本週在 PTT 的發文數，相對於前 8 週平均的偏離（取 `log1p` 後相減）。量的是發文數，不是搜尋量，所以不稱為 ASVI |
| 交易時段／非交易時段 | 交易日 09:00–13:30 為交易時段，其餘全部（平日盤前盤後、週末、假日）為非交易時段 |
| 週間／週末 | 原論文的日曆切法：週一至週五、週六日 |
| 開盤缺口 | 上週最後一個交易日收盤，到本週第一個交易日開盤的報酬 |
| 兩種推論標準 | 本研究主規格（個股＋週固定效果、雙重 cluster）與原論文的做法（僅個股固定效果、只按個股 cluster）。兩者的固定效果也不同。所有主表兩種並報 |
| 規格 A′／B／C | 用來拆開「期間」與「語料」的影響：A′ 為舊封存、2015–2024；B 為舊封存、2020–2024；C 為新直爬、2020–2024（主規格） |
| diagnostic | 控制變數不齊全時的結果標記，見 [`PROJECT.md`](PROJECT.md) §7 |
