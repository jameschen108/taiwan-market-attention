## 1. H1：週末係數在兩種推論標準之間跨過門檻——三個規格都一樣

`ret_oc_next`（論文的應變數），`H1-4 週間＋週末` 的**週末**係數：

| 規格 | 雙向 FE ＋ 雙重 cluster | 論文標準（個股 FE ＋ 個股 cluster） |
|---|---|---|
| A′ | β = 0.00053，t = 1.63 | β = 0.00089，**t = 3.15\*\*\*** |
| B | β = 0.00077，t = 1.61 | β = 0.00144，**t = 3.49\*\*\*** |
| C | β = 0.00063，t = 1.26 | β = 0.00119，**t = 2.68\*\*\*** |

週間係數三個規格都幾乎為零。**這個刀鋒狀態在換語料、換期間之後仍然穩定**——
不是資料造成的，是推論標準造成的。§0.2 要求「必須同時報兩種」是對的；只報任一種
都會給出相反的結論。

### 最強的發現不在主規格，而在缺口——但它撐不過漲跌停穩健性

`ret_gap_next`（上週五收盤 → 本週一開盤）的週末係數，主表 **六格全部 1% 顯著**：

| 規格 | 雙重 cluster | 個股 cluster | 排除次週觸及漲跌停後（2c／1c） |
|---|---|---|---|
| A′ | t = 4.30\*\*\* | t = 3.49\*\*\* | 3.41\*\*\* ／ **2.07\*\*** |
| B | t = 4.08\*\*\* | t = 3.08\*\*\* | 2.75\*\*\* ／ **1.36（不顯著）** |
| C | t = 4.04\*\*\* | t = 3.21\*\*\* | 2.84\*\*\* ／ **1.75（不顯著）** |

週末關注度的效果幾乎全部落在週一的開盤集合競價上——但**其中相當一部分是漲跌停
截斷**。排除次週觸及漲跌停的 ticker-week（3.14% 的列）之後，係數掉 42%
（C：0.00064 → 0.00037），且在**原論文的推論標準下 B 與 C 都跌破 5%**。

### 但換成交易時段切法之後，同一條證據線撐得住

`H1-5 交易時段切法` 把關注度切成**交易時段**（交易日 09:00–13:30）與**非交易時段**
（其餘全部，含平日盤後與週末）。缺口的係數：

| 規格 | 非交易時段 主表（2c／1c） | 非交易時段 排除漲跌停 | 交易時段（主表 2c） |
|---|---|---|---|
| A′ | 4.62 / 4.66 | **4.54 / 3.68** | 1.45 |
| B | 4.69 / 5.08 | **4.97 / 4.30** | 0.57 |
| C | 4.33 / 4.74 | **4.25 / 4.07** | 0.30 |

**十二格全部 1% 顯著**（3 規格 × 主表／排除漲跌停 × 兩種推論標準），而交易時段窗口
在任何一格都不顯著（|t| 最大 1.45）。係數同樣掉約 38%，但 **t 值幾乎不動**——
被排除的漲跌停列帶走的是雜訊，不是效果。

> **這比週間／週末的切法乾淨。** 論文的週間／週末切分在台股設定下混了兩件事：
> 平日盤後的討論被歸進「週間」，而它與週末討論是同一種行為（市場關著時累積的
> 關注度）。
>
> **新的是缺口，不是切法。** 交易時段窗口在 v1 就有（`src/features/sessions.py`，
> 由**文章**時戳算出，pttweb 也有），所以 A′ 與 B 都跑得出這一格；v1 缺的是
> `ret_gap_next` 這個應變數（§5.0）。這條證據線需要的是**報酬三段拆解**，
> 不是分鐘級留言時戳——早先的敘述把來源記錯了。
>
> 界線同上：論文沒有把應變數拆成缺口，**不得寫成複製**。
> 而且 `H1-5` 的兩個窗口在 `ret_oc_next` 上都不顯著，這條線只存在於缺口。

> **界線**：論文與 v1 都沒有量過這一段（§5.0）。這是 v2 新增的證據線，
> **不得寫成「複製了論文的某某結果」**，也不得在不附上這張穩健性表的情況下
> 稱它為「最穩健的發現」。

注意這裡兩種推論標準的**相對關係反轉**：`ret_oc_next` 上個股 cluster 給出較高的
t 值，缺口上則是雙重 cluster 較高。「哪一種比較保守」不是固定的，取決於應變數的
週別共變結構。

## 2. H3 機制：兩條管道仍分不開

規格 C，雙重 cluster：

| | 週間 | 週末 |
|---|---|---|
| 非三大法人 ROI | **−0.0020（t = −2.32）\*\*** | +0.0015（t = 1.94）\* |
| 異常周轉率 | +0.0054（t = 6.97）\*\*\* | +0.0031（t = 3.34）\*\*\* |

§6.2 的判讀表預期「週間 → ROI 顯著、週末 → Turnover 顯著」＝資訊處理。實際
**週間 → ROI 是負的**，那不是任一條管道直接預測的形狀，不塞進表裡的分類。

兩個制度混淆的穩健性都做了（`LIMITATIONS.md` §12）：加 `dt_ratio` 控制後 ROI 係數
幾乎不動（−0.0020 → −0.0019）；排除次週處置週後周轉率係數 0.0031 → 0.0029。
**混淆是真的，但沒有驅動這兩個結果。**
