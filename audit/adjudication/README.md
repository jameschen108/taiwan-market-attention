## 相對 v1 的方法改良：延伸實體改為資料驅動

v1 的阻擋延伸規則（統一→統一證券、中華電→華電、平台聚集→台聚）是人工一筆一筆
看出來的。**人工只看得到抽到的那 550 筆，看不到的機制就留在資料裡。**

v2 改成資料驅動（`src/universe/extension_profile.py`）：對每個簡稱寫法掃全語料，
統計它左右緊接 1–3 字的分布；佔比高的延伸很可能是另一個實體。再以**語料中的真實
上下文**（不是人造探測字串）實測現行規則有沒有擋住。

兩個必要的技術細節，少了任一都會讓清單失去意義：

1. **純數字的「延伸」必須排除。** 「1102亞泥」不是汙染，是**代號緊接簡稱**，
   是最強的正面證據。不排除的話漏網清單會被它塞滿。
2. **必須用語料真實上下文測試。** 用「華電信 股價」去測會漏掉阻擋規則靠的是
   **前面**那個「中」字——探測字串把它切掉了，於是每一個 `blocked_before` 規則
   都會被誤報成漏網。

## 自動初判的分工

自動初判**刻意設計成與比對器獨立**——若只是重跑比對器，每一筆都會是「正確」，
那等於沒判。用的是比對器沒用到的訊號：代號與簡稱是否互相印證、命中是否在標題、
命中是否只出現一次而內文很長、以及延伸實體剖析。

| 初判 | 筆數 | 佔分析用 | 人工該做什麼 |
|---|---:|---:|---|
| `auto_correct` | 298 | 45.2% | 覆核即可（抽 20 筆獨立驗證初判本身的正確率） |
| `needs_review` | 274 | 41.5% | **逐筆裁決** |
| `suspect_weak` | 68 | 10.3% | **逐筆裁決**（證據薄弱，優先） |
| `suspect_ambiguous` | 11 | 1.7% | **逐筆裁決**（集團泛稱，優先） |
| `suspect_wrong` | 9 | 1.4% | **逐筆裁決**（疑似誤配，最優先） |

`audit/ptt_review_adjudicated_pttcc.csv` 已依 `review_priority` 排序，可疑者在最前面。

### v1 未識別的錯誤機制（本輪新增）

| # | 機制 | 例 |
|---|---|---|
| E7 | **人名撞股名** | 陳南光（前央行副總裁）→ 南光(1752) |
| E8 | **時事／司法案件名** | 京華城案 → 華城(1519)。**2023–24 與華城行情同期，汙染與應變數同時發生，比隨機雜訊更糟** |
| E9 | **TDR／海外子公司** | 泰金寶-DR(9105) → 金寶(2312) |
| E10 | **斷詞錯誤遠比 v1 所知普遍** | v1 只找到中華電／平台聚兩例；本輪另有 和成長、和成本、溫和成、和大家、大成長、一片欣欣、中國化、美國化 |

可能跨越詞邊界**，而 267 檔中 194 檔是兩字簡稱。
