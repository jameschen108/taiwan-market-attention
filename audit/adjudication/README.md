# 歸屬正確率抽驗（v2）

## 判讀者身分（必讀）

**本輪為機器抽驗：判讀由 Claude（LLM）執行，不是人工。** 這與 v1 相同。

v1 的對應文件把 LLM 判讀標為「不能直接充當人工抽驗」；v2 明確改為**以機器抽驗
為交付標準**。差別必須寫清楚：機器判讀的是「命中片段與其上下文是否指涉該檔上市
公司」，它看得到的是語意，看不到的是**判讀者本身的系統性偏誤**：同一個模型導出
修正規則、又用同一個模型驗收，兩輪之間的獨立性只來自樣本，不來自判讀者。
第二輪因此**剔除了與第一輪重疊的 102 筆**，但判讀者相同這一點無法消除。

`PROJECT.md` §4：v1 的七道比對規則可移轉到新語料，**95% 這個數字不可移轉**。
本目錄就是重驗的工作區。

## 流程

```bash
python3 -m src.ptt.index_jsonl                            # 隨機存取索引
python3 -m src.universe.extension_profile --source pttcc  # 語料延伸剖析
python3 -m src.universe.name_vintage                      # 名稱時效性
python3 -m src.universe.review_sample   --source pttcc    # 分層抽樣
python3 -m src.universe.review_evidence --source pttcc    # 逐筆證據
python3 -m src.universe.auto_verdict    --source pttcc    # 規則初判
# 修正後的獨立重抽
python3 -m src.universe.review_sample   --source pttcc --seed 424242 --tag _round2
```

抽樣 685 筆（分析用 645 ＋ bulk 旗標檢核 40），分層沿用 v1：`tier:*` 各 50、
18 個碰撞群組成員各 20、`mode:*` 各 50、`bulk` 40。只在主樣本期間抽樣。

| 分析用樣本 | 645 | 542 |

記於 `LIMITATIONS.md` §6.3。

## 相對 v1 的方法改良

### 延伸實體改為資料驅動

v1 的阻擋規則是人工一筆一筆看出來的，而**人工只看得到抽到的那 550 筆**。v2 改為
掃全語料統計每個簡稱左右緊接 1–3 字的分布（`extension_profile.py`），再以**語料
中的真實上下文**實測現行規則有沒有擋住。

兩個必要的技術細節：

1. **純數字的「延伸」必須排除**。「1102亞泥」不是汙染，是代號緊接簡稱，是最強的
   正面證據。不排除的話漏網清單會被它塞滿。
2. **必須用語料真實上下文測試**。阻擋規則靠的是**前面**那個「中」字，用「華電信
   股價」這種探測字串去測會把它切掉，於是每個 `blocked_before` 都會被誤報成漏網。

初判結果見 `extension_leaks_classified.csv`：30 種 `wrong`（涉及 15 檔、語料出現
13,439 次）、11 種 `correct`（安泰銀行、統一超商、南港輪胎等公司全名，**不得**加
阻擋規則）、4 種 `ambiguous`（王品集團、六福村、味全龍）。

### 名稱時效性（`name_vintage.py`，v1 完全沒查過）

宇宙清單的 `name_short` 是**建清單當下（2026）**的簡稱，樣本卻是 2020–2024。
掃全語料統計每個代號旁緊鄰的中文名：

| ticker | 宇宙作 | 語料常用 | 逐年 |
|---|---|---|---|
| 2340 | 台亞（41%） | **光磊（47%）** | 2019–20 全為光磊、2021 轉換、2022 後全為台亞 |

這是**更名**，不是誤配。實測提到「光磊」的 250 篇文章中有 **77 篇（30.8%）完全
配不到 2340**。那是漏掉的關注度，不是誤加的。已將「光磊」補為 2340 的變體。

2723（美食-KY）與 2327（國巨*）的「差異」只是 `-KY`／`*` 後綴，變體清單已涵蓋，
非問題。
